# PinBoard

Zbulo dhe ruaj pin-e frymëzuese në një masonry grid elegant — demo lokale.

## Veçori

- Masonry grid me 18 pin-e frymëzuese (lartësi të ndryshueshme, responsive)
- Kërkim live sipas titullit dhe tag-eve
- Ruajtje pin-esh me butonin "Ruaj" — ruhen në localStorage
- Tab "Të ruajturat" që filtron vetëm pin-et e ruajtura
- Modal me detaje për çdo pin (titull, tag-e, buton Ruaj)
- Buton "Përziej" për renditje të rastësishme
- 100% demo lokale — asnjë server, asnjë llogari
